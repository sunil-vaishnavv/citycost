# CityCost Backend Documentation
## Overview
This document describes the backend architecture using PostgreSQL + Groq, replacing the original demo/hardcoded data system, while maintaining complete backward compatibility.

---
## Folder Structure
```
cost-of-living-comparison-tool/
├── db/
│   ├── schema.pg.sql             # COL core schema (PostgreSQL)
│   └── editorial-*.pg.sql        # Editorial Engine schema (applied on boot)
├── lib/

│   ├── city-repository.ts        # Database operations for cities

│   └── logger.ts                 # Database logging

└── .env.example                  # Updated environment variables
```

## API Flow
### GET /api/cities
1. Try Numbeo API (if configured, for backward compatibility)
2. Else, try the PostgreSQL database for all cities
3. Else, fall back to original DEMO_CITIES array

### GET /api/city_prices?query=...
1. Try Numbeo API (if configured)
2. Else, try PostgreSQL:
   a. Check if city exists (cache hit)
   b. If yes: return data from PostgreSQL
   c. If no: generate via Groq, save to PostgreSQL, then return
3. Else, fall back to original demo/procedural generation

### POST /api/ai_summary
1. Try Groq API for summary
2. Else, fall back to original procedural summary

---
## Cache Strategy
- **Cache Hit**: When city data exists in PostgreSQL
- **Cache Miss**: When city data is not in PostgreSQL; generate via Groq and save for next time
- **Log Every Request**: Every API call is logged to `logs` table with timing, cache status, errors

## Database Setup
1. Create a PostgreSQL database (Coolify → New Resource → PostgreSQL) and copy its connection URL into `DATABASE_URL`
2. Apply the COL schema: `psql "$DATABASE_URL" -f db/schema.pg.sql`
3. Editorial Engine tables (`db/editorial-*.pg.sql`) are created automatically on server boot

---
## Backward Compatibility
- All original APIs work exactly as before
- Original DEMO_CITIES array remains as final fallback
- Numbeo API still supported if configured
- All frontend code unchanged
- All SEO/robots/sitemap routes unchanged

---
## Installation Steps
1. `npm install`
2. Copy `.env.example` → `.env` and fill in secrets
3. Create the PostgreSQL database and set `DATABASE_URL`
4. Apply `db/schema.pg.sql` to the database
5. Run: `npm run dev` (or `npm run start` for production)
