# Cost of Living Comparison Tool

A comprehensive cost of living comparison tool for cities worldwide.

## Features

- Compare cost of living between any two cities
- Real-time data from Numbeo API
- AI-powered summaries
- Responsive design with dark mode
- SEO-optimized pages for city comparisons
- Print-friendly reports

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GROQ_API_KEY` in `.env` to your Groq API key
3. Run the app:
   `npm run dev`
